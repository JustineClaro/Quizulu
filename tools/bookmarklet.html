Quizulu importer

Copies the questions from an itexamanswers.net exam page into Quizulu's format, with the red answers starred.

1. Install (once)

  1. Show your bookmarks bar: Ctrl + Shift + B in Chrome or Brave.
  2. Drag this button onto the bookmarks bar:
    Copy to Quizulu Loading…

Can't drag it? Click , then right-click the bookmarks bar → Add page…, name it “Copy to Quizulu”, and paste the code into the URL box.

2. Import an exam

  1. Open an exam page on itexamanswers.net.
  2. Click Copy to Quizulu on your bookmarks bar. A panel shows how many questions it found, including “Show answer” cards for matching and fill-in questions.
  3. Set the Type (Module, Quiz, Final…) and a short Title such as Module 18-20, then click Copy to clipboard.
  4. Make a new file in questions/, type # DEV OPS on the first line, paste below it, and add the file name to questions/subjects.txt. The copied text already has its ## heading, so don't type another.
  5. If the panel said some questions have images, run python tools/save-images.py to save them into the project.

Updating the importer

If the importer gets fixed or improved, delete the old bookmark and drag the button again.
